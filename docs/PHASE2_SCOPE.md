# 95-point redesign Phase 2

Fixed constraints:
- Keep the existing black background and core CSS language.
- Keep API, admin, data and server configuration unchanged.
- Improve usability without adding heavy libraries.

## Phase 2A — SERVICES architecture
- Reorganize all 8 services into two clearly labelled groups without removing any service.
- Add short audience jump links near the SERVICES hero.
- Keep service-to-contact query values unchanged.
- Improve touched mobile readability using the brighter gray baseline.
- Add safe-area and reduced-motion handling.
- Add WORKS to the SERVICES primary navigation.
- Soften unqualified absolute marketing claims where found.

## Phase 2B — cross-page navigation
- Add WORKS consistently to ABOUT / BLOG / CONTACT and other main public navigation.
- Remove external brands from primary navigation where they compete with the sales funnel.
- Keep external brands discoverable from WORKS / ABOUT.

Phase 2A is intentionally reviewed and merged before Phase 2B so regressions remain small and easy to isolate.
