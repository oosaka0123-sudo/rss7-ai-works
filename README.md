# RSS7 AI Works — GitHub管理用ファイル

現行サイトとして特定したHTML・公開記事・画像・データ・関連設定を整理したものです。
秘密情報を含む自動投稿ファイル、旧メールフォーム、旧資産、ログ、不審PHP、内包ZIPは同梱していません。ブログ管理HTMLの固定パスワードによるオフラインログインは除去し、認証APIが利用できない場合はログイン不可にしました。

## 利用範囲と本番運用

これはGitHubでコードを管理するための構成です。既存サーバー全体のバックアップや、そのまま置き換えられる完全な配備物ではありません。

- 主要6ページ、公開ブログ記事30件、公開記事データ等を保持しています。
- ブログAPIは、セッション認証、CSRF対策、入力検証、公開領域外の記事正本、画像実体検査を備えています。本番専用設定は `api/config.local.php` に置き、Gitへ登録しません。
- 自動投稿プログラムは同梱していません。サーバー上の既存ファイルはこの作業では変更していません。将来登録する場合は秘密情報を環境変数等に分離してください。
- images/og-image.jpg は受領時点から不足しています。
- お問い合わせ画面は `api/contact.php` へ送信し、ロリポップのメール機能で受け付けます。本番専用の宛先・送信元設定はGitへ登録しません。
- 旧ページ・旧フォーム・サーバー固有設定は含まれていません。GitHubの内容で本番を丸ごと同期・削除しないでください。
- GitHub PagesだけでPHPのAPIや自動投稿を実行する構成にはなっていません。

ロリポップへの自動反映は [docs/PRODUCTION_DEPLOY.md](docs/PRODUCTION_DEPLOY.md) を参照してください。

## 登録時の注意

このフォルダの中身だけを登録してください。ZIPや上位フォルダ全体を登録しないでください。
別保存の非公開保留フォルダと元ZIPには認証情報や危険なコードが残るため登録禁止です。
.gitignore は誤登録を減らす補助で、秘密情報検査の代わりにはなりません。
